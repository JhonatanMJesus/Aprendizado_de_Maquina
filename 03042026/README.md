# Aula 04/03/2026 — Programação Orientada a Objetos e Python

Revisão de fundamentos de Python com foco em Programação Orientada a Objetos (POO), aplicada a cenários práticos.

## Conteúdo

### `Fundamentos.ipynb`
Revisão dos fundamentos da linguagem Python necessários para a disciplina.

### `OOP.ipynb`
Conceitos de Programação Orientada a Objetos:
- Definição e instanciação de classes
- Herança e polimorfismo
- Encapsulamento de atributos e métodos
- Classes abstratas e implementação de métodos
- Aplicação prática: gerenciamento de sensores IoT e sistema de autenticação com validação de senha

### `Tarefa0403.ipynb`
Tarefa referente aos conteúdos da aula: exercícios de fixação sobre POO.

## Objetivo
Nivelar o conhecimento em Python e POO como base para os algoritmos de Machine Learning desenvolvidos ao longo do semestre.
