# Aula 11/03/2026 — Manipulação de Dados com Pandas

Introdução à biblioteca Pandas para análise e manipulação de dados tabulares, base essencial para qualquer pipeline de Machine Learning.

## Conteúdo

### `pandas.ipynb`
Fundamentos da biblioteca Pandas:
- Criação e manipulação de **Series** e **DataFrames**
- Leitura e escrita de arquivos CSV
- Filtragem, seleção e transformação de dados
- Carregamento do dataset Titanic como exemplo prático

## Objetivo
Dominar as estruturas de dados do Pandas para limpeza, exploração e preparação de datasets que alimentarão os modelos de ML da disciplina.
