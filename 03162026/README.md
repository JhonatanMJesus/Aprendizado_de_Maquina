# Aula 16/03/2026 — Regressão Linear Simples

Implementação de Regressão Linear Simples do zero utilizando NumPy, com aplicação em predição de preços de imóveis.

## Conteúdo

### `regressao.ipynb`
Implementação manual da regressão linear simples:
- Cálculo dos coeficientes **a** (intercepto) e **b** (inclinação) pela fórmula analítica
- Construção da equação da reta: ŷ = a + bx
- Visualização da linha de regressão sobre os dados

### `regressao_kc.ipynb`
Aplicação da regressão linear simples no dataset de imóveis King County (Seattle):
- Predição de preços de casas com base em uma variável (ex: área)
- Análise exploratória e visualização dos dados

### `Exemplo Regressão Linear.xlsx - Planilha1.csv`
Dataset de exemplo utilizado no notebook `regressao.ipynb`.

### `kc_house_data.csv`
Dataset King County com dados reais de venda de imóveis, contendo variáveis como área, número de quartos, banheiros, preço, entre outras.

### `Regressão Linear.pdf`
Material teórico de apoio sobre Regressão Linear Simples.

## Objetivo
Compreender o funcionamento matemático da regressão linear e implementá-la sem o uso de bibliotecas de alto nível, reforçando a intuição por trás do algoritmo.
