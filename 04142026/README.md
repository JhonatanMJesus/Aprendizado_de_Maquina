# Aula 14/04/2026 — KNN: Exercícios de Revisão e Fixação

Exercícios práticos para consolidar o entendimento do algoritmo K-Nearest Neighbors, com três cenários de classificação distintos.

## Conteúdo

### `respostas.ipynb`
Soluções dos três exercícios de KNN:

- **Exercício 1** (`knn_dataset_exercicio_1.txt`): Segmentação de consumo de clientes em categorias baixo, médio e alto.
- **Exercício 2** (`knn_dataset_exercicio_2.txt`): Classificação de desempenho de funcionários.
- **Exercício 3** (`knn_dataset_exercicio_3.txt`): Aplicação adicional do KNN em outro contexto de classificação.

Cada exercício explora:
- Análise de fronteiras de decisão
- Impacto do valor de k no resultado
- Limitações do algoritmo KNN

### `knn_dataset_exercicio_1.txt` / `_2.txt` / `_3.txt`
Datasets dos três exercícios práticos.

### `10. KNN - Exercícios de Revisão e Fixação.pdf`
Enunciado dos exercícios com orientações e contexto de cada problema.

## Relação com outras aulas
Esta aula é a **sequência de exercícios** da implementação apresentada em `04132026`.

## Objetivo
Fixar o algoritmo KNN por meio de problemas variados, desenvolvendo intuição sobre a escolha do k e as limitações do método.
