# Aula 05/05/2026 — Perceptron (Teoria e Datasets)

Introdução teórica ao algoritmo Perceptron, o modelo mais simples de rede neural, com apresentação dos datasets que serão usados na implementação.

## Conteúdo

### `13. Perceptron.pdf`
Material teórico sobre o Perceptron:
- Estrutura do neurônio artificial e função de ativação **Sign**
- Regra de aprendizado do Perceptron
- Problemas linearmente separáveis
- Limitações do Perceptron simples (ex: XOR)
- Base para redes neurais multicamada

### Datasets de Treino e Teste
Três pares de datasets para diferentes cenários de classificação binária:

| Arquivo | Descrição |
|---------|-----------|
| `train_dataset1.csv` / `test_dataset1.csv` | Cenário 1 — dados linearmente separáveis |
| `train_dataset2.csv` / `test_dataset2.csv` | Cenário 2 — variação de distribuição |
| `train_dataset3.csv` / `test_dataset3.csv` | Cenário 3 — caso mais complexo |

## Relação com outras aulas
Esta aula apresenta a **teoria e os dados**. A aula `05122026` traz a implementação completa do Perceptron usando estes mesmos datasets.

## Objetivo
Compreender o funcionamento matemático do Perceptron e preparar o terreno para sua implementação prática na aula seguinte.
